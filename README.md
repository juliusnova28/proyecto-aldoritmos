## Tema y Regla de Negocio
Este sistema gestiona una **Almacenadora de Materia Prima**. La regla de negocio especial asignada es la **Alerta de Stock Mínimo**, la cual notifica al usuario cuando un producto, después de una venta, cae por debajo o igual a su cantidad mínima permitida.

Esta regla está implementada aplicando **Herencia y Polimorfismo** mediante una clase abstracta `ReglaNegocio` y la subclase `AlertaStockMinimo`.
